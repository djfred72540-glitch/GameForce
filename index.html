Aide à l’installation

Windows : si « Windows a protégé votre ordinateur » s’affiche, clique sur Informations complémentaires puis Exécuter quand même.
Mac : décompresse le .zip, ouvre le .dmg et glisse le jeu dans Applications. Au premier lancement : clic droit sur l’app → Ouvrir. Si le message « endommagé » apparaît, ouvre le Terminal et tape : xattr -cr "/Applications/Game Force.app"
Android : ouvre le fichier .apk et autorise l’installation d’applications inconnues quand le téléphone te le demande.
